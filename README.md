# Кузьмин Виктор — сайты для бизнеса в Якутске

Продающий сайт-портфолио веб-разработчика: главная с тарифами и заявкой, портфолио с фильтром по нишам,
шесть демо-сайтов реальных бизнесов Якутска («как могло бы быть»), SEO-страницы, политика и согласие по 152-ФЗ,
админка на русском.

Стек: Python 3.13, Django 5.2 LTS, SQLite, шаблоны Django, чистый CSS и немного ванильного JS. Без Node.js.

> ## ⚠️ ВНИМАНИЕ: смените пароль админки перед запуском в интернете
>
> По умолчанию логин и пароль админки — `admin` / `admin` (из файла `.env`). Это только для своего компьютера.
> **На сервере обязательно задайте свой пароль** — иначе сайт откажется запускаться (так задумано):
>
> 1. в `.env` впишите `ADMIN_PASSWORD=ваш-длинный-пароль`;
> 2. выполните `python manage.py setup --reset-admin-password` (или `python manage.py changepassword admin`).

## Запуск за 5 минут (Windows)

Нужен Python 3.13 (`py -3.13 --version`). Одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File run.ps1
```

Скрипт сам создаст окружение `.venv`, поставит пакеты, подготовит базу и контент и запустит сайт.
Или вручную, по шагам:

```powershell
py -3.13 -m venv .venv
.venv\Scripts\pip.exe install -r requirements.txt
.venv\Scripts\python.exe manage.py setup
.venv\Scripts\python.exe manage.py runserver 3000
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin/ — `admin` / `admin`

При первом запуске `manage.py` сам создаёт `.env` из `.env.example` со случайным `SECRET_KEY`.

### Что делает `manage.py setup`

1. Применяет миграции (создаёт базу `db.sqlite3`).
2. Создаёт админа из `ADMIN_USERNAME` / `ADMIN_PASSWORD` в `.env` (если его ещё нет).
3. Заполняет пустые таблицы: тарифы, FAQ, каналы связи, шесть демо-сайтов и кейсов
   (факты — из `docs/research/*.json`, тексты — из `portfolio/demos/*.json`). Правки из админки не затирает.
   `--refresh-demos` — перезаписать демо и кейсы заново.
4. Копирует фото демо из `research-private/` в `media/` и подставляет превью кейсов.

### Фото бизнесов не лежат в репозитории

Фото из карточек 2ГИС — чужие, поэтому в публичный репозиторий они не попадают (папка `research-private/`
в `.gitignore`). Без неё демо-сайты показываются со стоковыми фото или нейтральными заглушками.
Чтобы на сервере были настоящие фото, скопируйте папку отдельно, например:
`scp -r research-private root@сервер:/srv/makao/` и выполните `manage.py setup` ещё раз.
Если владелец бизнеса попросит — удалите его фото и демо (в админке: «Демо-сайты» → снять «Опубликован»).

## Админка: что где

| Раздел | Что можно |
|---|---|
| Заявки | список с датой, именем, телефоном, сообщением, отметкой согласия; статус «новая / в работе / закрыта» |
| Кейсы | добавить, изменить, загрузить превью (сохранится в WebP), снять пометку «Демо-проект» |
| Отзывы | только с согласия автора и имя без фамилии — иначе на сайте не показываются |
| Тарифы | цены, сроки, что входит; сроки в днях — для даты «готов к …» на главной |
| Каналы связи | WhatsApp, Telegram, телефон, VK… — добавляются без кода (сейчас стоят **плейсхолдеры**) |
| Настройки и реквизиты | ФИО, ИНН, ОГРНИП (сейчас **плейсхолдеры**), email для запросов по ПДн, версии документов |

## Telegram-бот (уведомления о заявках)

В Telegram приходит только «Новая заявка №N» и ссылка на неё в админке — **без имени и телефона**
(передача персональных данных за рубеж запрещена без отдельных условий). Пока токена нет, отправка просто
пропускается.

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, придумайте имя — получите токен.
2. Напишите своему боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найдите `"chat":{"id": ...}`.
4. Впишите в `.env`: `TELEGRAM_BOT_TOKEN=...` и `TELEGRAM_CHAT_ID=...`, перезапустите сайт.

## Что сделать по закону (152-ФЗ) — ваш список дел

1. **До запуска подать уведомление в Роскомнадзор** об обработке персональных данных:
   [pd.rkn.gov.ru](https://pd.rkn.gov.ru) → «Уведомление об обработке ПДн». Сайт собирает имя и телефон.
2. **Вписать реквизиты в админке** («Настройки и реквизиты»): ИНН, ОГРНИП, email для запросов — сейчас там нули.
3. **Показать юристу** тексты `/policy/` и `/consent/`. Это аккуратные шаблоны, а не юридическая консультация.
4. Заменить плейсхолдеры WhatsApp/Telegram в «Каналах связи» на свои.

Что уже сделано: отдельное согласие (с 1 сентября 2025 года оно оформляется отдельно), чекбокс не отмечен
по умолчанию и проверяется на сервере, в заявке сохраняются дата и время согласия и версии документов,
cookie-плашка, Яндекс.Карта только по клику, данные — на сервере в России.

## Деплой

Подробно — [docs/DEPLOY.md](docs/DEPLOY.md): VPS Reg.ru (Ubuntu), gunicorn + Caddy (бесплатный HTTPS) + systemd,
привязка домена Reg.ru. Коротко: `bash deploy/install.sh ваш-домен.ru <адрес репозитория>`.

## Проверки

```powershell
.venv\Scripts\pip.exe install -r requirements-dev.txt
.venv\Scripts\python.exe -m coverage run manage.py test
.venv\Scripts\python.exe -m coverage report
```

Lighthouse главной (боевой режим, `DEBUG=False`): телефон — скорость 95, доступность 100, практики 100, SEO 100;
компьютер — 100 по всем. Отчёты — в `docs/lighthouse/`.

```

deploy/      Caddyfile, systemd-служба, образец .env для сервера, скрипт установки
```
