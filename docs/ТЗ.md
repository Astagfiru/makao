# ТЗ проекта: сайт-портфолио «Кузьмин Виктор»

Версия: утверждена 2026-10-21 (обновлённая, со стеком Python + Django).

# РОЛЬ
Ты — senior full-stack разработчик и дизайнер. Создай с нуля и запусти продающий сайт-портфолио
веб-разработчика из Якутска «Кузьмин Виктор». Он продаёт услуги по созданию сайтов через доску объявлений
Doska.Ykt.Ru. Сайт — главное доказательство компетенции: портфолио повышает конверсию объявления в 4,6 раза.

# КОНТЕКСТ ПРОДАЖИ
- Лендинг от 15 000 ₽ / 5–7 дней, корпоративный сайт от 35 000 ₽ / 10–14 дней,
  интернет-магазин от 60 000 ₽ / от 2 недель. Оплата поэтапно 30/70, работа по договору.
- Аудитория: малый и средний бизнес Якутска (услуги, общепит, строительство, торговля, салоны,
  автосервисы), который ищет подрядчика на доске объявлений.
- Контакты в футере и блоке CTA: WhatsApp и Telegram (пока плейсхолдеры).
  В админке контакты — список каналов: можно добавить новые (телефон, VK и т.д.) без правки кода.

# ГЛАВНАЯ ФИЧА — КЕЙСЫ ИЗ РЕАЛЬНОГО ГОРОДА
1. Найти 4–6 реальных живых мелких и средних бизнесов Якутска из разных ниш, у которых нет сайта
   или сайт явно устарел. Ниши для примера: кофейня, автосервис, стоматология, стройка, салон красоты,
   доставка еды.
   Источники: Instagram (их там много), doska.ykt.ru (бизнесы, которые дают объявления без сайта),
   2ГИС, Яндекс.Карты, VK, spravker.ru.
   Схема: Kimi через мой Edge собирает кандидатов со ссылками на источники, ты проверяешь каждый факт.
   Сначала показать мне 6–8 кандидатов с источниками. Я утверждаю 4–6, и только потом пишется код.
2. Для каждого — ДЕМО-САЙТ (прототип редизайна «как могло бы быть») в стиле своей ниши:
   современный дизайн, адаптив, реальные данные из открытых источников (название, адрес, услуги, цены).
   Фото — только заглушки, без чужих фото и логотипов.
   ФИО владельцев и сотрудников не публиковать: это персональные данные.
3. На каждом демо — плашка «Демо-концепт, не официальный сайт <название>» и запрет индексации (noindex).
4. Ссылок на Instagram на сайте нет: Meta признана в РФ экстремистской. Instagram — только как источник поиска.
5. Карточка кейса в портфолио: превью, ниша, что сделано, кнопка «Смотреть демо», пометка «Демо-проект».
   Пометку можно снять в админке, когда бизнес станет реальным клиентом.

# СТЕК (изменён по моему решению: Node/JS/TS не используем)
- Python 3.13 + Django + SQLite (файл, без внешних сервисов). SQL руками не пишем, всё через ORM Django.
  Где нужна гибкость «как в NoSQL» (например, блоки демо-сайтов) — JSONField.
- Шаблоны Django (рендер на сервере), чистый CSS и минимум ванильного JS в браузере.
  Без jQuery и без фронтенд-фреймворков.
- Запуск: python -m venv .venv → pip install -r requirements.txt →
  python manage.py setup (миграции + seed + админ) → python manage.py runserver 3000.
  Можно добавить скрипт запуска одной командой.
- SEO: sitemap.xml (django.contrib.sitemaps), robots.txt, meta og:, ЧПУ (slug).
- Производительность: картинки в webp через Pillow, lazy-load. Lighthouse Performance и SEO ≥ 90
  на главной (замерять Lighthouse через Edge).
- Деплой:
  - хостинг Reg.ru (VPS с Ubuntu в РФ, домен тоже на Reg.ru);
  - .env.example; README «запуск за 5 минут»;
  - gunicorn + Caddy (бесплатный HTTPS Let's Encrypt) + systemd вместо pm2;
  - инструкция по привязке домена в Reg.ru.
  VPS и домена пока нет.

# ЮРИДИЧЕСКИЕ ТРЕБОВАНИЯ — строго по законам РФ (152-ФЗ «О персональных данных», требования Роскомнадзора)
Делать в режиме автопилота, без лишних вопросов.
1. Политика конфиденциальности /policy — стандартный документ, адаптированный под 152-ФЗ:
   - оператор: Кузьмин Виктор, реквизиты — плейсхолдеры из админки;
   - какие данные собираются: имя, телефон, текст заявки, технические cookies;
   - цели, правовые основания, сроки хранения;
   - права субъекта, порядок отзыва согласия;
   - меры защиты;
   - данные хранятся и обрабатываются на серверах в РФ (хостинг Reg.ru);
   - дата и номер версии документа.
2. Согласие /consent — отдельный документ: с 1 сентября 2025 года согласие оформляется отдельно
   от других документов.
3. Формы — под каждой формой обязательный чекбокс:
   - НЕ отмечен по умолчанию;
   - текст «Я даю согласие на обработку персональных данных» со ссылками на /consent и /policy;
   - без галочки форма не отправляется, проверка на сервере, а не только в браузере;
   - в заявке сохраняются дата и время согласия и версия политики.
4. Telegram — зарубежный сервис: передача туда имени и телефона — это трансграничная передача данных.
   Поэтому в бот приходит только «Новая заявка №N» + ссылка на заявку в админке, без имени, телефона и текста.
5. Cookie-баннер — лёгкий ванильный скрипт:
   - плашка о сборе cookie с кнопкой «Принять» и ссылкой на политику;
   - выбор сохраняется в localStorage;
   - плашка не сдвигает вёрстку и не портит Lighthouse.
   Яндекс.Карта (ставит свои cookies) грузится только после согласия или по клику — это ещё и ускоряет страницу.
6. Футер — блок правовой информации:
   - Кузьмин Виктор, ИНН / ОГРН(ИП) — плейсхолдеры, редактируются в админке без правки кода;
   - ссылки на /policy и /consent;
   - строка «Информация на сайте не является публичной офертой».
7. Отзывы — только с согласия автора, имя без фамилии.
8. В README и отчёте — что сделать мне самому:
   - подать уведомление об обработке ПДн в Роскомнадзор (pd.rkn.gov.ru) до запуска сайта;
   - вписать реквизиты в админке;
   - показать документы юристу. Тексты — шаблоны, а не юридическая консультация.

# ДИЗАЙН
- «Вау», продуманный, уровень awwwards. Использовать дизайн-скиллы taste-skill и ui-ux-pro-max.
- Концепция «Полюс холода»:
  - основная тема тёмная, «полярная ночь»;
  - светлая тема — «иней»;
  - акцентный цвет — северное сияние.
- Переключатель темы в шапке, красивый и продуманный:
  - иконка солнце ↔ луна с плавным превращением;
  - новая тема «разливается» кругом от кнопки (View Transitions API);
  - выбор запоминается, страница не мигает при загрузке, кнопка доступна с клавиатуры.
- Эффекты — лёгкие, без фреймворков, чтобы держать Lighthouse ≥ 90:
  - переливы сияния на фоне;
  - крупная типографика;
  - анимации при прокрутке;
  - «живые» карточки кейсов с подсветкой за курсором.
  При prefers-reduced-motion анимации выключаются.
- Шрифты: Inter, Onest или Manrope, файлы лежат локально, без CDN.
