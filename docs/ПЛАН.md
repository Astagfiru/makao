# План сайта «Кузьмин Виктор — сайты для бизнеса в Якутске»

Черновик для согласования, 2026-10-21. Основа — [ТЗ](ТЗ.md). Код начинаем писать только после «ок».

## 1. Из чего состоит сайт (простыми словами)

- **Django** — «движок»: по адресу страницы находит нужный шаблон, подставляет данные из базы и отдаёт готовый HTML.
- **SQLite** — база данных в одном файле `db.sqlite3`. Кейсы, отзывы, тарифы, заявки лежат там.
  Работаем с ней только через Python (ORM), SQL вручную не пишем.
- **Админка** `/admin` — готовая панель Django на русском: в ней вы правите кейсы, тарифы, контакты, реквизиты
  и смотрите заявки. Без правки кода.
- **Шаблоны + CSS + чуть-чуть JS** — внешний вид. JS только для темы, cookie-плашки и анимаций.

## 2. Устройство проекта

```
makao/
├── config/            настройки Django (читают .env), адреса страниц, sitemap
├── core/              главная, SEO-страницы, контакты, правовые страницы,
│                      настройки сайта, каналы связи, тарифы, отзывы, FAQ
├── portfolio/         ниши, кейсы, демо-сайты
├── leads/             заявки, проверка согласия, уведомление в Telegram
├── templates/         HTML-шаблоны (base, страницы, темы демо-сайтов)
├── static/            CSS, JS, шрифты (woff2 локально), иконки
├── docs/              ТЗ, план, исследование бизнесов, инструкция по деплою
├── deploy/            Caddyfile, systemd-юнит, пример .env для сервера
├── manage.py
├── requirements.txt   Django 5.2 LTS, Pillow, python-dotenv, WhiteNoise, gunicorn
├── .env.example
├── run.ps1            запуск одной командой на Windows
└── README.md          «запуск за 5 минут» + деплой + что сделать по Роскомнадзору
```

Почему так: три небольших приложения по смыслу (контент / портфолио / заявки) — легко найти нужное,
каждое можно проверять отдельно. Django 5.2 — версия с долгой поддержкой (до апреля 2028).

## 5. Юридическая часть (152-ФЗ) — как сделаю

- **Форма заявки**: галочка согласия не отмечена по умолчанию, ссылки на `/consent/` и `/policy/`.
  Проверка **на сервере**: без галочки заявка не сохраняется, даже если обойти браузер.
  В заявку пишутся дата/время согласия и версии документов.
- **Тексты** политики и согласия — шаблоны в коде, реквизиты подставляются из админки. Версия и дата —
  в одном месте в настройках; поменяли текст → подняли версию → новые заявки пишут новую версию.
- **Telegram**: в бот уходит только «Новая заявка №N» и ссылка на неё в админке. Ни имени, ни телефона,
  ни текста. Нет токена в `.env` — отправка тихо пропускается.
- **Cookie-плашка**: снизу поверх страницы (не сдвигает вёрстку), «Принять», ссылка на политику,
  выбор в localStorage. Яндекс.Карта грузится только по клику или после согласия.
- **Футер**: Кузьмин Виктор, ИНН/ОГРН(ИП) из админки, ссылки на документы,
  «Информация на сайте не является публичной офертой».
- **Отзывы** публикуются, только если в админке отмечено «согласие автора получено»; имя без фамилии.
- **Демо-сайты**: только данные из открытых источников, без ФИО, без телефонов; логотип — наш текстовый
  вариант названия (чужие файлы логотипов не берём); фото — по правилу ниже.
  Вместо контактов бизнеса — нейтральная заглушка и ссылка «Заказать такой сайт».
- **Фото на демо** (решение пользователя 2026-10-22): берём реальные фото из карточки бизнеса в 2ГИС.
  Если их мало, плохое качество или не разобрать, что на них, — лицензированный сток (Unsplash/Pexels).
  Ограничения: без фото с узнаваемыми лицами людей (ГК РФ ст. 152.1); фото бизнесов не коммитим в публичный
  репозиторий — лежат в `research-private/` (в git не попадает), `manage.py setup` подставляет их в media;
  подпись «Фото: 2ГИС» и ссылка на карточку; по просьбе владельца — сразу убрать.
  В приоритете — реальные данные (прайс, часы, услуги) и правдоподобные бизнес-процессы.
- В README и отчёте — ваш список дел: уведомление в Роскомнадзор (pd.rkn.gov.ru) до запуска,
  реквизиты в админке, показать тексты юристу.

## 6. Безопасность

- Секреты и пароли только в `.env` (в git не попадает). `.env.example` — образец без секретов.
- Боевой режим (`DEBUG=False`): если у админа всё ещё пароль `admin` — сервер **не запускается**.
  В README крупное предупреждение.
- Cookie сессии и CSRF — `HttpOnly`, `Secure` на сервере; заголовки безопасности (HSTS, запрет
  встраивания в чужие сайты и т.п.).
- Форма: скрытое поле-ловушка от ботов и ограничение «не больше 5 заявок за 10 минут с одного адреса»
  (адрес не сохраняется в базе — только временно в памяти).
- Загрузка превью: только картинки, перекодируются в webp через Pillow, ограничение размера.

## 7. Дизайн «Полюс холода»

- Тёмная тема «полярная ночь» по умолчанию, светлая «иней», акцент — градиент северного сияния
  (зелёный → бирюзовый → фиолетовый). Цвета — CSS-переменные, обе темы из одного набора.
- Переключатель: солнце ↔ луна с плавным превращением, новая тема «разливается» кругом от кнопки
  (View Transitions API), выбор запоминается, страница не мигает при загрузке (крошечный скрипт в `<head>`),
  управление с клавиатуры.
- Эффекты: мягкие переливы сияния на фоне, крупная типографика, появление блоков при прокрутке,
  подсветка карточек кейсов за курсором. При «уменьшить движение» в системе — всё статично.
- Шрифты: Onest или Manrope (кириллица, лицензия OFL), файлы woff2 лежат в проекте.
- Детали (палитра, сетка, типографическая шкала) подберу со скиллами taste-skill и ui-ux-pro-max на итерации «Главная».

## 8. Скорость и SEO (цель Lighthouse ≥ 90)

- Один CSS-файл, JS с `defer`, никаких внешних CDN и счётчиков, шрифты с `font-display: swap`.
- Картинки webp с размерами и `loading="lazy"`; WhiteNoise отдаёт статику со сжатием и кэшем.
- `<title>`, description, og:-теги, canonical, микроразметка Schema.org для услуг, ЧПУ-адреса.
- Демо-сайты: `noindex` в meta и в заголовке ответа, не в sitemap.
- Замер: автоматически, `npx lighthouse` с Edge на главной (Performance и SEO ≥ 90), отчёт в `docs/lighthouse/`.

## 11. Решения по ходу работы (2026-10-22)

1. **Данные демо** собраны из карточек 2ГИС через Edge (только чтение) → `docs/research/<id>.json`; сырые данные и фото — в `research-private/` (в git не попадает).
2. **Фото**: не берём импортированные из Instagram, альбом «Персонал», кадры с узнаваемыми лицами, фото пациентов «до/после» (медицинские данные), постановку с оружием (Topmen). Телефоны на вывесках и госномера размыты.
3. **Санья**: блока «до/после» нет — достоверных пар в 2ГИС нет, а фото повреждений от посетителей похожи на фото к жалобам. Вместо него — «Как проходит ремонт» и объяснение ПДР. Темы отзывов — только по отзывам об автосервисе (в карточке смешаны отзывы о кафе и гостинице по тому же адресу).
4. **Дентал Даймонд**: цен в 2ГИС нет — цены на демо не показываем. Кабинет — стоковое фото (CC BY 4.0) с подписью. Старый сайт stomykt.ru не существует (NXDOMAIN).
5. **S`Нежный**: у 7 позиций прайса исправлена явно сбитая категория (цены не менялись).
6. **Отзывы на главной**: выдуманных отзывов нет. В seed — только черновик-пример (не опубликован); блок появится, когда в админке будет отзыв с согласием автора.
7. **Дизайн главной** (taste-skill, направление «Цветовые главы», seed 2097316629): палитра и шрифты — из ТЗ; блок цен заменён на «Тарифы ступенями» (три тарифа). Градиент сияния и подсветка карточек — требование ТЗ, остальное по правилам скилла.
8. **Node** используется только как внешний инструмент (Lighthouse, скрипты taste-skill), в проект не входит.
9. **gunicorn** ставится только на Linux (маркер в requirements.txt); `manage.py` при первом запуске сам создаёт `.env` из `.env.example`.
10. **Первый экран**: `h1` — «Сайты под ключ в Якутске», сразу под ним — «Для бизнеса — от 15 000 ₽, запуск от 5 дней»: полная фраза ТЗ в двух строках заголовка не помещается на телефоне.
11. **Тема по умолчанию** — всегда «полярная ночь» (по ТЗ основная тема тёмная); выбор посетителя запоминается.
12. **Живая деталь главной**: даты «готов к …» у тарифов считаются от сегодняшнего дня (по времени Якутска).
13. **Превью кейсов** — скриншоты демо; в них фото бизнесов, поэтому они лежат в `research-private/previews/`, а `setup` подставляет их в кейсы.
14. **Кэш на сервере** — файловый (`.cache/`), чтобы ограничение частоты заявок было общим для всех процессов gunicorn.
15. **Демо**: в подписях — только формулировки самих бизнесов («по заводским данным», «Ваше мужское пространство», «Качество и атмосфера»); обещаний от их имени не добавлял.
16. **2026-10-22, правки пользователя:** слово «демо» заменено на «примеры работ», адрес — `/primery/<slug>/` (старые `/demo/…` перенаправляются).
17. **Функционал примеров** — «песочница» в сессии посетителя: запись на время по часам 2ГИС, тестовая оплата (без полей карты), корзина/калькулятор, статус по номеру, новости, кабинет владельца (статусы, цены, новости, выходные). Длительность услуг в источниках нет — это настройка владельца, в примере стоят значения по умолчанию.
18. **Главная:** примеры работ — вкладки с названиями и один большой пример со стрелками (вместо горизонтальной ленты); этапы — схема, где видно все шаги и точки оплаты 30% и 70%; блок заявки без фото, белая карточка формы; аккуратный подвал; компактная cookie-плашка; фильтр ниш в портфолио без перезагрузки.
