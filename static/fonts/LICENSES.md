# Шрифты

Все шрифты — под лицензией SIL Open Font License 1.1 (текст лицензии — `OFL.txt`), файлы взяты из Google Fonts
и лежат локально (без CDN).

| Файл | Шрифт | Где используется |
|---|---|---|
| `onest.woff2` | Onest (The Onest Project Authors), подмножество: латиница, кириллица с якутскими буквами, ₽ | главный сайт и тексты демо |
| `manrope-*.woff2` | Manrope (Mikhail Sharanda) | демо стоматологии |
| `nunito-*.woff2` | Nunito (Vernon Adams) | демо химчистки |
| `oswald-*.woff2` | Oswald (Vernon Adams) | демо барбершопа |
| `unbounded-*.woff2` | Unbounded (NaN) | демо салона |
| `russo-*.woff2` | Russo One (Jovanny Lemonad) | демо автосервиса |
| `cormorant-*.woff2` | Cormorant Garamond (Christian Thalmann) | демо цветочной студии |
| `lora-*.woff2` | Lora (Cyreal) | текст примера цветочной студии |
| `exo2-*.woff2` | Exo 2 (Natanael Gama) | текст примера автосервиса |
| `robotocond-*.woff2` | Roboto Condensed (Google) | текст примера барбершопа |
| `montserrat-*.woff2` | Montserrat (Julieta Ulanovsky) | текст примера салона |
